# Vayuyaan Write for Us page

A standalone, responsive contributor-guidelines page for Vayuyaan.

## Preview locally

Open `index.html` in a browser. The page loads the shared `../style.css` and uses Vayuyaan's existing GitHub Pages assets.

## Before publishing

- Confirm that `https://vayuyaan.com/contact-us/` is the correct submission route.
- Consider adding a dedicated editorial email address or submission form.
- Confirm the canonical URL matches the final published route.
- Review the WordPress logo URL used in the page header. If it does not resolve, replace it with the current logo URL.
- If the page is intended for the main WordPress site, use this file as a design/content reference and build it in WordPress. A GitHub Pages deployment under the existing repository will be on the GitHub Pages URL, not automatically on `vayuyaan.com`.

## Content intent

The page invites original, practical contributions on Arduino, ESP32, sensors, robotics, IoT, electronics fundamentals and troubleshooting. It does not promise publication or a particular backlink attribute.
