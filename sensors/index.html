Match the sensor to the task

Different modules produce different signals. Confirm voltage and output type from the documentation for your exact module.

01 · DISTANCE

HC-SR04 Ultrasonic Sensor

Uses an ultrasonic pulse and measures its return time to estimate distance. Best for many non-contact distance projects where the target can reflect sound.

Check: trigger and echo wiring, timing, target angle and the sensor's voltage requirements.

02 · OBJECT DETECTION

IR Sensor Module

Many reflective IR modules detect changes in reflected infrared light. Actual range and output behavior depend on the module and surface.

Check: indicator LEDs, sensitivity adjustment, ambient light and sensor height.

Read the IR sensor guide →
03 · LIGHT LEVEL

LDR Sensor

An LDR changes resistance as light levels change. A voltage divider can turn that resistance change into a measurable analog voltage.

Check: resistor value, analog input wiring and the room's lighting when calibrating.

DEBUGGING CHECKLIST

When readings do not look right

Work through these checks before changing several parts of a circuit at once.

1. Confirm power and ground

Check the module's rated supply voltage, verify polarity, and ensure sensor and controller grounds are connected when required.

2. Test one signal at a time

Use a small sketch or simple meter measurement to confirm the module changes output as the target or light level changes.

3. Account for the environment

Target material, angle, sunlight, nearby objects and electrical noise can all affect readings. Test under the conditions where the project will run.
