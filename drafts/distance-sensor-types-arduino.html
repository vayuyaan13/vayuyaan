Distance Sensor Types for Arduino: Ultrasonic vs IR vs ToF

Choosing a distance sensor is not just about the longest advertised range. The target, lighting, mounting space, response time, voltage and type of output all affect which module will work best in your project.

Distance sensors help a microcontroller detect an object or estimate how far away it is. However, different sensor technologies measure different signals. An ultrasonic module measures the travel time of sound, a reflective infrared (IR) module detects reflected light, and a Time-of-Flight (ToF) sensor estimates distance from emitted light returning to its receiver.

That difference matters. A low-cost IR obstacle module may only tell you whether an object is nearby; it does not necessarily return a distance in centimetres. A ToF module can return a numerical distance over a relatively compact field of view, while an ultrasonic sensor can be useful when you need to measure across a wider gap. None is best for every situation.

Quick answer: which distance sensor should you choose?

  • For a beginner Arduino project on a tight budget: start with an HC-SR04 ultrasonic module when the target is suitable and the environment is controlled.
  • For basic line or object detection: use a reflective IR module if you only need a detection signal, not a calibrated distance measurement.
  • For compact short-range distance measurement: consider a ToF module such as the VL53L0X, after checking its datasheet and the lighting conditions.
  • For damp environments or water-level experiments: consider a waterproof-probe ultrasonic model, but confirm the exact version's minimum range, output mode and whether its control board must remain dry.
  • For outdoor or safety-critical equipment: do not rely on a hobby sensor alone. Select a sensor with suitable environmental ratings and validate it under real operating conditions.
Important distinction“IR sensor” describes a broad family. A reflective IR obstacle sensor, an analog triangulation sensor and a ToF sensor that uses infrared light do not provide the same type of output. Check the exact module model rather than choosing by the word “IR” alone.

1. Ultrasonic distance sensors: when the HC-SR04 makes sense

An ultrasonic sensor sends a short burst of sound and measures how long the echo takes to return. For a typical HC-SR04, the Arduino triggers the module, measures the ECHO pulse and estimates the distance. Because sound travels to the target and back, the calculation divides the round-trip distance by two.

distance_cm = echo_time_us * 0.0343 / 2;

This approximation uses a speed of sound of about 0.0343 centimetres per microsecond near room temperature. Actual readings depend on temperature, target geometry, the module and the surrounding environment.

If you want to understand the practical limits of ultrasonic measurements in more detail, read our how ultrasonic sensor range and distance are calculated. Use the stated range as a starting point, then test your own target and mounting setup.

Advantages

  • Easy to demonstrate with a basic Arduino sketch.
  • Returns a numerical distance estimate rather than only a yes/no signal.
  • Useful for many indoor obstacle-detection and educational projects.

Limitations to plan for

  • Soft materials can absorb sound, while angled surfaces may reflect it away from the receiver.
  • Small targets may not return a strong echo.
  • Nearby objects, mounting geometry and repeated pings can affect readings.
  • A common HC-SR04 Echo output is around 5 V logic; do not connect it directly to a 3.3 V-only GPIO unless the board documentation confirms compatibility.

If you decide the HC-SR04 fits your project, review the HC-SR04 module specifications specifications before buying. Then use the practical HC-SR04 pinout and wiring before building the circuit. Check your specific module's pin labels and timing requirements.

2. IR sensors: proximity detection is not always distance measurement

A common reflective IR obstacle sensor emits infrared light and detects some of the light reflected from a nearby object. Many low-cost modules compare the received signal with a threshold and switch their digital output when the signal crosses that threshold.

This makes them useful for line-following robots and simple object-presence detection. However, the switching point can change with surface colour, material, angle, ambient light, sensor height and the module's sensitivity adjustment. A digital output marked HIGH or LOW does not tell you that an object is a particular number of centimetres away.

Some IR distance sensors use analog output and signal-processing optics to estimate distance. Those are a different class of device from a basic obstacle-detection board. For analog models, use the exact model's datasheet curve; do not assume a linear relationship between voltage and distance.

Choose reflective IR when

  • You need to detect a line, edge or nearby object.
  • The target path is predictable and you can calibrate the sensor in its real mounting position.
  • You can test the effect of different surfaces and ambient lighting.

For a moving robot, test the sensor at its final height and angle. A module that detects a white test card on a desk may behave differently over black tape, glossy flooring or bright sunlight. For a project example, see our guide to using ultrasonic sensors to detect obstacles in robots.

3. Time-of-Flight sensors: compact optical ranging

Time-of-Flight (ToF) modules estimate distance from the travel time of emitted light. The VL53L0X from STMicroelectronics is one example. ST specifies measurement up to 2 metres for this device; that figure is a manufacturer specification, not a guarantee that every target and environment will deliver the same performance.

ToF modules are compact and often communicate with a microcontroller over I²C. This can make them attractive when a project needs a numerical reading from a small sensor board. They are not automatically more accurate in every condition, however. The exact module, target, field of view, cover material, ambient light and integration all matter.

Before using a ToF board

  • Confirm the exact sensor IC and breakout-board documentation.
  • Check whether the board accepts your controller's supply voltage and logic levels.
  • Check its I²C address and ensure SDA and SCL are connected to the correct pins.
  • Test the target materials and lighting expected in the final project.

A ToF board and an ultrasonic module should not be compared using only the largest range number in a product listing. Compare the range you actually need, the target and environment, the update rate, the field of view and the quality of the readings.

4. Waterproof-probe ultrasonic sensors

Modules such as the JSN-SR04T family use a separate ultrasonic probe connected by a cable to a controller board. This construction can help when the sensing face needs protection from moisture or when the electronics should sit away from the measurement point.

Do not assume every version has the same usable range or interface. Different revisions may have different minimum distances, operating modes and output formats. Also, a waterproof probe does not automatically make the exposed control PCB, connectors or wiring waterproof. Protect the whole assembly according to its actual environmental rating.

For a tank or water-level project, mount the probe securely above the surface, check that the tank geometry does not create unwanted echoes, and test the minimum measurable distance. Condensation, foam, turbulent surfaces and internal obstructions can affect the result. Never use a hobby module as the sole protection against overflow or another hazardous condition.

5. How to choose the right distance sensor

  1. Define the measurement. Do you need a numerical distance, a simple object-present signal, line detection or level estimation? This choice rules out many unsuitable modules immediately.
  2. Set the real distance range. Write down the nearest and farthest distance you must measure. Include a margin rather than designing around a module's advertised maximum.
  3. Describe the target. Consider its size, surface, colour, angle and whether it moves. Sound and light sensors react differently to these factors.
  4. Check the environment. Indoor light, direct sunlight, rain, condensation, dust, temperature and nearby surfaces can change sensor performance.
  5. Confirm electrical compatibility. Check supply voltage, output voltage, current, interface and controller input limits. A 5 V supply rating does not prove that every signal pin is safe for 3.3 V logic.
  6. Check the mounting space. Consider the sensor's field of view, minimum range, blind zones, probe size and cable length.
  7. Test before finalising. Compare readings with a known reference at several distances and on the actual target. Record the results and repeat under expected operating conditions.

6. Arduino wiring and voltage compatibility

There is no universal wiring diagram for every sensor. A typical HC-SR04 uses TRIG and ECHO, while many reflective IR boards use a digital OUT pin, and a VL53L0X breakout typically uses I²C signals SDA and SCL. Waterproof ultrasonic versions may support more than one output mode.

7. Common sensor-selection mistakes

  • Choosing by maximum range alone: the sensor may not detect your target reliably at that distance.
  • Confusing proximity with ranging: a threshold-based IR module often reports detection, not centimetres.
  • Ignoring minimum range: some ultrasonic and optical sensors cannot measure very close objects reliably.
  • Assuming all versions match: modules with similar names can have different pinouts, interfaces or specifications.
  • Skipping electrical checks: supply voltage and signal logic are separate requirements.
  • Trusting one test reading: compare repeated measurements and test the real target, not only a convenient flat object.
  • Using a hobby sensor for safety protection: use an appropriately rated system for safety-critical monitoring.

Frequently asked questions

Which distance sensor is best for Arduino?

It depends on the task. The HC-SR04 is a useful starting point for basic ultrasonic distance experiments. A reflective IR module suits simple line or object detection, while a ToF sensor can suit compact optical ranging. Verify the exact sensor's specifications and test conditions before choosing.

Is an IR sensor the same as an ultrasonic sensor?

No. An ultrasonic sensor measures reflected sound timing. An IR sensor uses infrared light, but its output may be a detection threshold, an analog signal or a ToF distance reading depending on the technology.

Can an HC-SR04 measure up to 4 metres?

Many HC-SR04 modules advertise a nominal range of about 2–400 cm. The practical range depends on the module and target, so do not assume reliable detection at 4 metres in every setup.

Is the VL53L0X a laser distance sensor?

It is a ToF ranging sensor that uses an infrared VCSEL emitter. ST specifies a range up to 2 metres for the VL53L0X, but performance depends on the sensor setup and measurement conditions.

Can I connect every distance sensor directly to an ESP32?

No. Check the supply and logic levels of the exact module and the ESP32 board's input limits. A sensor powered from 5 V may still produce a signal that is unsafe for a 3.3 V-only GPIO.

Which sensor should I use for water-level measurement?

A waterproof-probe ultrasonic module can be suitable for some non-critical level measurements when mounted correctly above the surface. Check its version-specific minimum range, interface and environmental limits, then test with the actual tank and liquid conditions.
