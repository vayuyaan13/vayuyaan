## Maintenance checklist
- Keep canonical URLs aligned with each page's live URL.
- Update `sitemap.xml` whenever pages are added, removed, or renamed.
- Use internal links between relevant learning pages.
- Ensure each page provides unique, useful instructional content rather than existing only as a doorway to another site.
- Check Google Search Console's URL Inspection and sitemap status; sitemap inclusion does not guarantee indexing.

## Content quality
Prefer first-hand test notes, accurate code and wiring diagrams, specific troubleshooting guidance, component requirements, and expected results. Avoid thin pages, repeated keywords, and link schemes.
